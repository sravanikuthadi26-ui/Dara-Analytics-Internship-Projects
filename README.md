# Data-Analytics-Internship-Projects


## About This Repository
This repository contains two data analytics projects completed as part of my internship at Elevate Labs. The projects focus on financial performance analysis and startup investment trends using data analytics tools.

---

## Financial KPI Analysis for a Startup

**Objective:** To analyze the financial performance of a startup using Key Performance Indicators (KPIs).

**Tools Used:**
- Microsoft Excel
- Tableau
- Python (Pandas)

**Key Activities:**
- Collect and clean financial data.
- Analyze monthly revenue and expenses.
- Calculate burn rate and run rate.
- Calculate Customer Acquisition Cost (CAC).
- Calculate Customer Lifetime Value (LTV).
- Analyze LTV:CAC ratio.
- Create financial dashboards and visualizations.
- Perform monthly cohort analysis.

**Expected Outputs:**
- Financial KPI dashboard.
- Excel financial model.
- LTV:CAC analysis report.

---

## Startup Investment Analysis (Shark Tank Data)

**Objective:** To analyze startup investment trends using Shark Tank India/US datasets.

**Tools Used:**
- Microsoft Excel
- Python
- Tableau

**Key Activities:**
- Collect and clean startup investment data.
- Analyze industry-wise investments.
- Compare funding amounts requested and received.
- Analyze founder profiles and funding outcomes.
- Identify industry-wise investment trends.
- Create visual dashboards.

**Expected Outputs:**
- Startup investment dashboard.
- Industry-wise investment report.
- Founder success pattern summary.
